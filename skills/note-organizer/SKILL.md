# 笔记整理技能

把散落的笔记变成可复习的知识网络。核心判断：**整理的目的不是让目录好看，是让
「复习」这件事变得可以开始**——分不出优先级、找不到入口的笔记库，等于没有。

## 能力

- 给一批笔记定分类与标签体系（并且是能长期维护的，不是一次性整理）
- 生成周复习计划：按遗忘曲线与重要性排序，每天 15 分钟内可完成
- 找出笔记库的知识盲区：只记了结论没记推导、只记了名词没记用法的地方
- 合并重复笔记、拆分过长的笔记

## 核心流程

1. **先看清有什么**：用 `search_knowledge` 摸一遍相关笔记，别凭印象整理。
   拿不到全局视图时先问用户笔记大致分几类。
2. **归类用「一个笔记一个主类」**：标签可以多个，但主类只能一个，否则
   同一篇笔记会在复习时被重复安排或彻底漏掉。
3. **复习计划按三档排**：
   - **高频高价值**（岗位要用、面试会问、最近在学）：优先，每周至少一次
   - **低频高价值**（工具链细节、踩坑记录）：按月扫一遍即可
   - **低价值**（过期信息、二手转述）：直接归档或删掉，不要假装会复习
4. **盲区判定**：笔记里出现「是什么」但没写「怎么用/为什么」的条目，
   标记为待补推导；只在一处出现且没有上下文连接的概念，标记为孤立节点。
   这两类是复习时最容易卡住的地方。
5. **改完要能持续**：给出的是**规则**（分类命名约定、标签清单）而不是一份
   具体目录——下次有新笔记时用户得能自己判断放哪。

## 输出格式

给整理方案时先给「分类总览」（3-6 类，每类一句话说明收录标准），再给具体条目的
归位建议。复习计划给到「今天/明天/本周内」的粒度，别给月度计划——月度计划
没有可执行性。

## 示例

用户：我的笔记太乱了，帮我整理一下
助手：[触发 note-organizer 技能] 我先看看你库里都有什么笔记……然后给分类总览 +
具体归位建议 + 本周复习安排。
