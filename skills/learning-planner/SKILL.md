# 学习计划技能

把「我想学 X」变成「这周做什么、怎么算学会了」。核心判断：**没有检查点的计划等于
没有计划**——判断不了自己学没学会，就会一直在入门材料里打转。

## 能力

- 按目标反推要学的内容（先问目标，再拆内容，不从教程目录抄）
- 排出带检查点的周计划，每个阶段有可验证的产出物
- 诊断「学不会」的具体卡点（前置知识缺失 / 只读不写 / 目标过大 / 材料太难）
- 判断什么时候该换材料、什么时候该继续啃

## 核心流程

1. **先问三件事**：学会之后要做什么（面试？做项目？完成工作需求？）、
   每天能投入多少时间、现在已经会什么。**没有目标就无法判断哪些内容可以不学**，
   这是最常见的浪费来源。
2. **倒推内容清单**：从目标产出物出发，列出「要做成它必须会的 N 项」，
   再给每项标上「必须 / 顺带 / 可以不学」。
3. **每项配一个检查点**，形式必须是**能自己做出来的东西**：
   - 坏检查点：「理解装饰器」「熟悉 asyncio」
   - 好检查点：「手写一个带参数的装饰器并解释三层嵌套的作用」
     「用 asyncio.gather + Semaphore 写一个并发限制的抓取函数」
4. **排周计划**：按「每天 30-60 分钟可完成」切片，每天只安排一个主题。
   宁可少排，也不要把计划排到需要每天 3 小时——那种计划会在第 4 天崩掉。
5. **留出复习位**：每周最后一天不排新内容，用来重做检查点。学过的检查点
   两周后重做一次，做不出来就说明只记住了当时怎么写，没内化。

## 「学不会」的卡点诊断

| 现象 | 真实原因 | 对策 |
|---|---|---|
| 看懂了但写不出来 | 只读没写，缺肌肉记忆 | 合上教程重写一遍，卡住再回去看 |
| 每篇都看懂，连起来不懂 | 缺前置概念 | 往回找那个最关键的前置，专项补 |
| 学了两周还在第一章 | 材料太难或目标太大 | 换入门材料，或把目标砍到能两周做完 |
| 学完就忘 | 没有复习位，也没做检查点 | 加检查点 + 两周后重做 |
| 一直换材料 | 在用「找材料」逃避「开始做」 | 定死一份材料，先做完一个产出物 |

## 输出格式

计划按周给，每周列出：**主题 / 学习材料（具体到章节）/ 检查点 / 预计投入**。
第一周的计划要细到天，后面的周粗到主题即可——计划越长越不准确，
每周末根据实际进度重排下一周。

## 示例

用户：我想系统学一下 asyncio，怎么安排？
助手：[触发 learning-planner 技能] 先确认目标：是为了面试、还是手上有异步项目要改？
然后给内容清单 + 检查点 + 第一周计划。
