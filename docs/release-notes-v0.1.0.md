# 忆云 Agent v0.1.0

个人知识管理 Agent 的首个版本：导入笔记 / 面经 / 收藏文章后，用自然语言提问，
回答带来源引用；核心是**分层记忆 × 上下文治理 × Skill 化 × 评测与可观测**四件套。

## 下载

- `YiyunAgent-0.1.0-win64.zip` — Windows 64 位，解压后双击 `YiyunAgent.exe` 即用
  （绿色免安装，无需 Python 环境）

## 首次使用

1. 解压到任意目录，双击 `YiyunAgent.exe`
2. 点侧栏右上角 ⚙ → **供应商**，填入 LLM 与 embedding 的 API Key（OpenAI 兼容端点或 Anthropic）
3. 点输入框左侧的 ＋ 上传一篇笔记，或直接把文件拖进窗口
4. 开始提问

配置与数据都存在程序目录下的 `.env` 和 `data/`，换目录把这两样一起带走即可。

## 本版功能

- **三模式会话**：聊天 / 工作 / 代码（占位）；模式在会话创建时固定，各模式各一份列表
- **混合检索**：向量（sqlite-vec）+ BM25 + 实体三路召回，RRF 融合
- **分层记忆**：LLM 抽取候选 → 重要性评分 → 去重 → 冲突检测（不覆盖旧记忆）→ 敏感信息过滤
- **上下文治理**：工具结果清理 / 历史压缩 / token 预算，三策略独立开关
- **Skill 系统**：5 个内置技能（简历写作 / 面试准备 / 笔记整理 / 学习计划 / 项目创意）
- **定时任务**：cron + 模式 + 内容，到点自动开会话跑，结果走系统托盘通知
- **用量看板**：统计卡片 + 53 周热力图 + 请求日志，记录 token、缓存命中与耗时
- **桌面端**：pywebview 原生窗口 + pystray 托盘，点 X 最小化到托盘

## 系统要求

- Windows 10 / 11（64 位）
- 首次使用需自备 LLM API Key（OpenAI 兼容端点或 Anthropic）

## 已知限制

- 仅 Windows 桌面端
- 单用户本地场景，无多租户 / 权限体系
- 记忆过期只做时间衰减，高相关旧事实的「自信地错误」是开放问题
- 评测集 38 条，样本量不足以做统计显著性检验，结论以组间相对对比为准

## 从源码运行

```bash
pip install -e .
cp .env.example .env      # 填入 API Key
python -m uvicorn app.main:app --port 8765
```

测试：`python -m pytest tests/ -q`（600 条）
